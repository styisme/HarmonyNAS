# HarmonyNAS 终极使用与运维指南

本指南是 HarmonyNAS 的官方标准说明书。无论你是初次接触鸿蒙的普通用户，还是想要榨干设备性能的极客，这里包含了从零部署、多设备自适应操作、相册备份、网络映射（WebDAV/FTP）到极端故障排查的所有细节。

---

## 第一章：服务端 (Server) 部署与初始化

服务端是整个鸿蒙 NAS 生态的大脑，建议将其部署在一台长期插电的鸿蒙设备（手机、平板或 2in1）上。

### 1.1 安装与首次启动
1. **获取安装包**：由于鸿蒙系统的签名机制，请通过 DevEco Studio 编译生成的 `.hap` 包，或者通过应用市场获取正式版。
2. **网络权限授予**：首次打开应用，系统会请求“网络访问”权限，**必须允许**，否则无法监听任何端口。
3. **创建数据沙箱**：鸿蒙的安全机制极其严格，第三方应用默认无法访问全盘。应用启动时，会在系统分配的沙箱目录下创建 `filesDir` 作为 NAS 的根目录（通常在 `/data/storage/el2/base/haps/entry/files` 之下）。

### 1.2 服务端驾驶舱（参数调优）
服务端主界面采用了鸿蒙原生的卡片化设计，所有的配置实时生效：
- **基础设置**：修改设备名称（将显示在 LocalSend 发现列表中）；修改 Web (默认 8080)、WebDAV (默认 8081)、FTP (默认 2121) 的端口。
- **服务开关**：一键启停 LocalSend 接收端（53317端口）和 DLNA 投屏（SSDP发现）。你可以自定义 LocalSend 的 PIN 码（默认 1234），确保传输安全。
- **长时任务保活**：在应用启动时，系统会申请 `DATA_TRANSFER`（数据传输）长时任务，通知栏会出现一条常驻通知。**请勿手动划掉此通知**，这是系统允许 NAS 在息屏和退入后台时继续提供服务的唯一合法凭证。

### 1.3 文件导入机制（如何放入文件？）
因为鸿蒙沙箱限制，你无法直接在 NAS 根目录拖入文件。你有三种方式将文件放入 NAS：
1. **通过 Web/客户端**：从手机或电脑上直接上传文件。
2. **系统文件选择器**：在服务端界面点击“导入文件”，调用鸿蒙系统自带的 `DocumentViewPicker` 或 `PhotoViewPicker`，选择其他目录的文件授权给 NAS 拷贝至沙箱。
3. **网络协议**：通过电脑映射 WebDAV 或 FTP，像操作 U 盘一样把文件拖进去。

## 第二章：Web 网页端 (全功能浏览器访问)

网页端是零安装的最快入口。在同一局域网下，用任何设备的浏览器访问 `http://<NAS设备的IP>:8080` 即可。

### 2.1 鉴权与系统控制台
- **401 拦截**：若服务端开启了密码验证，浏览器会弹出原生输入框（默认 `admin` / `admin`）。
- **网页端设置**：点击页面右上角的 `⋮` 菜单，选择 `⚙️ 系统设置`。你可以直接在网页上修改管理员密码、动态调整服务端口、以及开关各项协议。
- **广告位机制**：网页端集成了 5 个自适应的广告展示位。若你在服务端配置了本地广告（`ad.json`），它们将优雅地显示在文件列表底部、主菜单内部或作为开屏展示，不干扰正常的文件操作。

### 2.2 文件管理核心操作
- **流媒体播放**：点击视频（MP4/MKV）或音频文件。后端完整支持 `Range` 分片请求，你可以随意拖动进度条，实现秒加载。
- **在线文本编辑**：点击 `.txt`、`.json` 等代码或文本文件，会弹出沉浸式的 Markdown 风格编辑器。修改后点击保存，文件会直接写回服务端沙箱。
- **在线解压**：点击 `.zip` 文件，选择“解压”。服务端会利用系统原生的 `@ohos.zlib` 引擎，在同级目录瞬间解压出文件夹。
- **免密分享外链**：点击文件选择“分享”，系统会生成一个带有 8 位随机 Token 的短链接（如 `/share/abcd1234`）。将这个链接发给局域网内的任何人，他们无需登录即可直接下载该文件。

### 2.3 局域网剪贴板
点击右上角的 `📋` 图标，你在这里输入的任何文字，都会瞬间同步到所有已连接的鸿蒙客户端、桌面端甚至其他网页端。这对于跨设备复制长链接或验证码极其有用。

## 第三章：鸿蒙客户端 (全设备自适应矩阵)

由于客户端采用了极致的 ArkUI 响应式设计，一套代码能够自动适配你的所有鸿蒙设备。

### 3.1 局域网并发扫描
1. 首次打开客户端，点击 `🔍 扫描局域网`。
2. 客户端会同时获取设备所有网卡的子网（如 192.168.1.x, 192.168.31.x），开启 64 线程并发探测 8080 端口。
3. 几秒钟内，屏幕上就会列出所有正在运行的 HarmonyNAS，点击即可自动填入 IP，输入账号密码完成连接。

### 3.2 相册自动增量备份
1. 在底部 Tab（或侧边栏）点击 `🖼️ 相册`，点击 `📥 备份照片`。
2. 客户端会调用 `photoAccessHelper` 读取本地系统相册，并请求你的权限。
3. **核心秒传原理**：客户端首先向服务端请求 `/Photos/` 目录下的所有文件名。接着遍历本地相册，**只有本地有、NAS 上没有的照片，才会被挑选出来上传**。彻底杜绝了重复传输浪费流量。
4. 上传过程中，顶部会显示真实的进度条与当前正在上传的文件名。

### 3.3 多设备形态自适应体验
- **在手机上**：采用经典的底部 Tab 导航，操作符合直觉。
- **在平板/2in1上**：自动切换为双栏（Split）布局。左侧是导航栏（文件、相册、设置），右侧是超大的文件网格瀑布流，完美利用了大屏空间。
- **在智慧屏（TV）上**：自动切换为全屏网格布局（无底部 Tab）。通过遥控器方向键移动时，焦点卡片会自动放大 1.1 倍并带柔和阴影。按确认键即可打开文件。
- **在智能手表上**：调整为单列卡片流，自动适配圆盘/方盘，边缘增加防遮挡 Padding，所有操作通过旋转表冠和点按完成。

## 第四章：全协议网络映射（让其他设备访问）

NAS 不仅仅在自家 App 里能看到，通过局域网协议，你可以让它无缝融入你的办公电脑。

### 4.1 映射 WebDAV 到 Windows
1. 打开电脑的“此电脑”，右键选择“映射网络驱动器”。
2. 文件夹地址输入：`http://<NAS设备的IP>:8081`（注意是 HTTP 不是 HTTPS，且端口是 8081）。
3. 勾选“使用其他凭据连接”，输入用户名和密码（默认 `admin` / `admin`）。
4. 等待几秒钟，你的 NAS 就会出现在“此电脑”的“网络位置”中，你可以直接在里面看视频、写代码、复制文件，与操作本地硬盘毫无区别。

### 4.2 连接原生 FTP
1. 打开电脑的“资源管理器”或任何 FTP 客户端（如 FileZilla）。
2. 在地址栏输入：`ftp://<NAS设备的IP>:2121`。
3. 服务端已完美适配 PASV（被动）模式，彻底解决了老旧路由器或防火墙拦截导致的“连接超时”问题，可以直接拖拽传输大文件。

### 4.3 LocalSend 互传（免装 App）
不需要在 NAS 上打开任何接收界面。
1. 在电脑或另一台手机上打开官方 LocalSend 应用。
2. 在网络设备列表中，你会发现一个名为 `HarmonyNAS`（或你自定义的设备名）的设备。
3. 点击发送，输入服务端驾驶舱里设置的 PIN 码（默认 1234）。
4. 文件会瞬间跨端传输，并自动落盘到 NAS 沙箱的 `/Download/LocalSend/` 目录下，同名文件会自动重命名为 `(1)`, `(2)` 避免覆盖。

## 第五章：深度故障排查 (Troubleshooting)

在极客使用的过程中，遇到报错是常态。以下是针对 HarmonyNAS 常见问题的排查指南：

### 5.1 为什么关闭屏幕或切出应用后， NAS 就连不上了？
- **原因**：鸿蒙系统的资源管控极其严厉，应用退入后台超过一定时间会被“冻结”甚至查杀，导致底层监听端口的 Socket 被强制回收。
- **解决**：请检查应用启动时，是否成功申请了 `DATA_TRANSFER` 长时任务。确保通知栏有“HarmonyNAS 正在运行”的常驻通知。并且不要在系统设置里把应用的电池优化设为“严格限制”。

### 5.2 Web 端提示 ERR_CONNECTION_REFUSED
- **排查 1**：服务端 App 是否在前台亮着绿灯？如果是红字，说明端口被其他应用占用了，请去“驾驶舱”把 8080 改成 8088 或其他端口。
- **排查 2**：检查你的 NAS 设备和电脑是否在同一个 Wi-Fi 下。如果开启了路由器的“访客网络”或“AP 隔离”，设备之间是互不相通的。

### 5.3 为什么打开文件列表，提示“空目录”？
- **原因**：这是鸿蒙沙箱的限制。默认根目录是 App 的内部存储空间（`filesDir`）。如果你没有上传过文件，也没有映射过本地图库，这里自然是空的。
- **解决**：通过网页端点击右下角的 `+` 上传文件，或者去客户端里点一下“相册备份”。

### 5.4 在线解压 zip 时提示“解压失败”
- **排查 1**：鸿蒙的 `@ohos.zlib` 引擎对部分包含特殊字符或超大嵌套目录的 ZIP 文件支持有限，建议尝试重新打包为标准 ZIP 格式。
- **排查 2**：检查设备存储空间是否已满。解压需要消耗与压缩包内文件等量的额外空间。

### 5.5 相册备份中途停止，或部分照片失败
- **原因**：可能是应用读取相册的权限被中途撤销，或者某张图片的格式（如 HEIC）在传输过程中出现异常。
- **解决**：重新点击备份按钮，NAS 的增量机制会自动跳过已上传成功的文件，专门重试那些失败的图片。

### 5.6 电视端遥控器焦点卡住了
- **原因**：鸿蒙 TV 端布局中，网格与网格之间有时候焦点计算会卡住。
- **解决**：按一下遥控器的“返回”键，重新进入列表；或者在设置中开启“强制网格对齐”。

---
**⚠️ 郑重提示**：局域网传输使用的是 HTTP 明文协议。如果在公共 Wi-Fi 下开启服务，请务必加上复杂的密码。一旦发现异常，请立即在驾驶舱点击“停止服务”。
